# ProTrace SOP — Microsoft Environment Migration & Architecture Guide

This document provides a step-by-step blueprint to recreate the entire **ProTrace SOP Motorsport & Aerospace Overhaul Tracker** natively within the **Microsoft Ecosystem** (Microsoft Azure, Power Platform, Azure SQL, Microsoft Entra ID, and .NET).

---

## 1. High-Level Microsoft Architecture

| Layer | ProTrace Current (Vite/React) | Microsoft Native Equivalent |
|---|---|---|
| **Frontend Web App** | React SPA + Tailwind CSS | **Azure Static Web Apps** or **Power Apps (Canvas App / Model-Driven)** |
| **Backend API Services** | Node.js / Express Server (`server.ts`) | **Azure Functions (.NET 8 / C#)** or **Azure App Service** |
| **Database & Persistence** | Cloud Firestore / IndexedDB / LocalStorage | **Azure SQL Database** or **Microsoft Dataverse** |
| **Authentication & Identity** | Custom Corporate Email Auth / Firebase Auth | **Microsoft Entra ID (Azure Active Directory)** |
| **Document & PDF Storage** | Client JS PDF Engine + IndexedDB | **Azure Blob Storage** or **Microsoft SharePoint Document Library** |
| **Workflow & Notifications** | Browser Audio Alarms & Local Events | **Power Automate (Flow)** + **Microsoft Teams / Outlook Connectors** |
| **Mobile & PWA Access** | PWA manifest + Service Worker (`sw.js`) | **Microsoft Power Apps Mobile** or **Windows Edge PWA** |

## 2. Step-by-Step Recreation Options

### Option A: Professional Developer Stack (Azure Static Web Apps + Azure SQL + .NET C#)
*(Recommended for exact UI preservation, high performance, and full control)*

1. **Deploy Frontend to Azure Static Web Apps**:
   - The existing React + Tailwind CSS code compiles directly into static assets.
   - Run: `az staticwebapp create --name protrace-sop-app --resource-group rg-protrace --source .`
   - Config file: Add `staticwebapp.config.json` for Microsoft Entra ID authentication route protection.

2. **Deploy Database to Azure SQL Database**:
   - Run the auto-generated Azure SQL DDL script (available in the app via the **Microsoft 365 Migration Package** download).
   - Tables created: `Units`, `IntakeRecords`, `PressureTestRecords`, `FlowTestPoints`, `CleanlinessAnalysisRecords`, `SignOffRecords`, `ActivityLogs`.

3. **Deploy Backend APIs to Azure Functions (.NET 8 / C#)**:
   - Replace Express API endpoints with C# Azure Functions (e.g. `GetUnitsFunction`, `UpdateStageFunction`, `GenerateCertificateFunction`).
   - Use Entity Framework Core (`EF Core`) to connect Azure Functions to Azure SQL.

4. **Integrate Microsoft Entra ID (Azure AD)**:
   - Register the application in Azure Portal under **App Registrations**.
   - Enable Single Sign-On (SSO) for corporate motorsport/aerospace customer domains (`@ferrari.it`, `@porsche.de`, etc.).

---

### Option B: Low-Code Enterprise Stack (Microsoft Power Platform)
*(Recommended for zero-code maintenance and rapid integration with Microsoft 365)*

1. **Database & Dataverse**:
   - Import the **Dataverse Entity Schema JSON** generated by `downloadMicrosoftMigrationPackage()`.
   - Primary Entity: `ps_serviceunit` (Service Unit).
   - Related Entities: `ps_intakerecord`, `ps_flowtestpoint`, `ps_pressuretest`, `ps_cleanlinessanalysis`.

2. **Power Apps Canvas / Model-Driven App**:
   - Build a Canvas App or Model-Driven App connecting directly to Dataverse.
   - Stage 01 - Stage 11 step progression maps to **Power Apps Business Process Flows (BPF)**.

3. **Power Automate (Flow) Workflows**:
   - **Quarantine Alert Flow**: Triggered when `ps_overallstatus` changes to `quarantined` -> sends Adaptive Card to Microsoft Teams channel and email to QA Lead.
   - **Certificate Dispatch Flow**: Triggered on Stage 11 QA Sign-Off -> generates PDF via Word Template connector and attaches to Outlook email.

## 3. Data Schema & SQL Scripts

The complete Azure SQL Server DDL and Power Apps Dataverse schema can be exported directly from the app interface by clicking **Microsoft 365 Suite** -> **Download Microsoft Migration Package**.

### Core Tables Summary:
- **`Units`**: Master unit metadata, serial numbers, customer allocations, current step ID, overall status, priority, SLA delivery dates.
- **`IntakeRecords`**: Initial damage checks, protection covers, exchange medium (Water to Oil, Oil to Oil, Water to Air), part drawing numbers.
- **`FlowTestPoints`**: 5-point dynamic flow curve measurements (20 Hz - 60 Hz).
- **`PressureTestRecords`**: Hydrostatic proof pressure hold tests (3 Bar to 210 Bar).
- **`CleanlinessAnalysisRecords`**: Gravimetric particle mass (mg) and ISO 16232 / AS9100D cleanroom verdicts.
- **`SignOffRecords`**: Final QA inspector authorization and protective bung sealing verification.
- **`ActivityLogs`**: Full immutable audit trail of all workshop stage transitions.
